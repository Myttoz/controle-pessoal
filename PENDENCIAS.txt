1. [ ] ⚠ PUBLICAR A API_KEY (SEGURANÇA — a API está ABERTA para a internet)
--------------------------------------------------------------------------------
Testado em 03/11/2026: testar-api → 2 OK / 3 FALHA.
  · GET sem chave → funciona (deveria bloquear)
  · GET com chave errada → funciona (deveria bloquear)
  · POST sem chave → executa (deveria bloquear)
Ou seja: a versão publicada ainda está com API_KEY vazia, mesmo que o
Config.gs local já esteja com a chave preenchida.

Como corrigir (5 minutos, ordem importa):
  1. Abrir o editor do Apps Script → Config.gs → confirmar a linha 148 com a
     chave. Se estiver vazia (''), colar o conteúdo inteiro de
     codigo/Config.gs → salvar (Ctrl+S).
  2. Implantar → Gerenciar implantações → caneta ✏️ →
     "Quem tem acesso" = Qualquer pessoa → Nova versão → Implantar.
  3. Rodar:  testar-api
     Resultado esperado: "5 OK, 0 FALHA(S)".

2. [ ] CRIAR A PLANILHA_MODELO E O BACKUP AUTOMÁTICO (no editor do Apps Script)
--------------------------------------------------------------------------------
O arquivo codigo/Backup.gs já está pronto (sintaxe validada). Falta você:
  1. Abrir o editor do Apps Script → novo arquivo → nome "Backup"
     → colar o conteúdo de codigo/Backup.gs → salvar.
  2. (Opcional) recolar codigo/Inicializacao.gs — mudou só num comentário
     que lista os passos 4 e 5.
  3. No seletor de funções (topo do editor), escolher
     "passo4_criarPlanilhaModelo" → ▶ Executar → autorizar permissões.
     → cria a "Planilha_modelo" (planilha vazia, estrutura intacta).
  4. Escolher "passo5_instalarBackup15dias" → ▶ Executar.
     → cria a 1ª cópia de segurança AGORA e instala o backup automático
       (a cada 15 dias, às 3h, no servidor do Google).
  5. Conferir no Google Drive: as cópias aparecem na mesma pasta da planilha.
