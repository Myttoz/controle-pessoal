PASSO 3.3 — Crie o repositório no GitHub
  1. Entre em https://github.com e faça login.

  8. Clique em "Generate token".
  9. Copie o token que começa com "ghp_..." e guarde. Ele só aparece uma vez.

 PARTE 8 — PROBLEMAS COMUNS E SOLUÇÕES
================================================================================

1) "Ação real desconhecida: dadosLocais"
   - O Auth.gs/Api.gs não foi atualizado OU a nova versão não foi publicada.
   - Repita os passos 2.4, 2.5 e 2.6.
   - Confirme em Gerenciar implantações se a versão ativa é a mais nova.

2) "Token inválido ou expirado"
   - Faça logout e login de novo.
   - Se persistir, confira se o Auth.gs novo foi publicado.

3) "Não autorizado" / erro de chave
   - Confira no Apps Script se o Config.gs publicado tem a API_KEY correta.
   - Confirme que a implantação está como "Qualquer pessoa".
   - A chave não deve ser digitada no app; o proxy injeta sozinho.

4) Versão web em branco ou 404
   - Confirme Settings → Pages → Source = GitHub Actions.
   - Confirme que o workflow "Publicar versão web" terminou verde.
   - Espere 2–3 minutos e recarregue com Ctrl+F5.
   - Confira se a URL termina com /controle-pessoal/.

5) Login na web não funciona, mas no desktop sim
   - A implantação do Apps Script pode estar restrita a "Qualquer pessoa com
     conta Google". Mude para "Qualquer pessoa" e publique nova versão.
   - Teste em uma janela anônima.
   - Veja o console do navegador (F12 → Console) e me envie o erro.

6) Sincronização fica "pendente"
   - Confira a internet.
   - Clique em "Sincronizar agora".
   - Veja se a aba DADOS_LOCAIS existe.
   - Se o erro for "JSON_INVALIDO", não edite a aba à mão; exporte o backup,
     limpe as linhas de dados da DADOS_LOCAIS (mantenha o cabeçalho) e importe
     o backup de novo.

7) "Dados locais com versão inválida na planilha"
   - Alguém editou a aba DADOS_LOCAIS à mão.
   - Exporte o backup no aparelho que estiver correto, limpe a aba (só os
     dados, mantenha o cabeçalho) e importe o backup.

8) Windows: "O Windows protegeu o computador"
